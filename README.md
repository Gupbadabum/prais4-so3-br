# PRAIS 4 — Brasil — Objetivo Estratégico 3 (SO3)

Este repositório reúne os fluxos computacionais, procedimentos metodológicos e
documentação associados ao desenvolvimento do Objetivo Estratégico 3 (SO3) do
PRAIS 4 para o Brasil.

O projeto está organizado segundo os três componentes do SO3:

- **SO3.1 — Ameaça de seca**
- **SO3.2 — Exposição da população à seca**
- **SO3.3 — Vulnerabilidade à seca**
